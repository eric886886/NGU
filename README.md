# NaxaStudio 首页（3D 粒子影片版）

英文版 `index.html`，中文版 `zh.html`。两个版本用同一套代码，右上角的 EN / 中文 互相链接。

## 创意

整个网站讲成一部可以用滚动条播放的影片。打开首页，屏幕中间只有一个发光的"想法"；往下滑，同一群粒子（电脑上约 15 万个，手机上约 6.5 万个）跟着故事变成十三章里的一个个光的"雕塑"。原来首页的内容，加上关于、AI 方案、起步 AI 方案、业务结果、ROI、Demo、案例、业务诊断、联系这些子页面的内容，全部按一个故事串起来：中文 56 段文字，英文 59 段，按正常阅读速度看完大约 10–13 分钟。看完以后页面像普通网页一样继续往下，是完整的联系表单和页脚。

没有一张图片、一个图标，所有画面都是这群粒子在三维空间里排出来的（three.js）。

滚动条就是进度条：滑多少，故事就走多少；往回滑就倒着放。不分页、不跳转，停在哪里，画面就停在哪里（哪怕正变到一半）。

### 一章怎么走

每一章只有一个形状，这一章的每一段文字是镜头的一个停靠点：镜头绕着这个雕塑走（从高处、贴着它、绕到侧面、靠近某一个细节），文字讲它的细节。比如"五个 AI 助手"这一章，镜头先从上面看整朵花，再一瓣一瓣地停在每个助手旁边（花在慢慢转，镜头跟着转），讲到哪个助手，那一瓣尖上的名字就亮起来，其他的变暗。

1. 镜头停住，这一段的标题一个字一个字（英文一个词一个词）浮上来，然后是正文、列表（一条接一条）和链接
2. 继续往下滑，文字往上飘走、变模糊，镜头飞到这一章的下一个停靠点
3. 一章讲完，整个形状汇成一条旋转的光流，沿着镜头的路线流向下一章；这时屏幕中下方出现一句旁白，像电影字幕，把两章接起来
4. 光流散开，拼成下一章的形状

### 旁白

原页面的文字一字不改；章与章之间的旁白是新写的：

| 位置 | 中文 | 英文 |
| --- | --- | --- |
| 想法 → 纳想 | 我们帮它长出形状。 | We help it take shape. |
| 首屏 → 关于 | 先说说，纳想为什么存在。 | But first, why NaxaStudio exists. |
| 关于 → 压力 | 可是走着走着，事情开始打结。 | But along the way, things get tangled. |
| 压力 → AI 方案 | 把每一个结，交给一个会做事的 AI 助手。 | Give each knot to an AI assistant that does the work. |
| AI 方案 → 起步方案 | 不用一次全部。先搭第一层。 | Not ready for every agent? Start with one practical layer. |
| 起步方案 → 业务结果 | 这样做，生意会看到什么变化？ | So what changes in the business? |
| 业务结果 → ROI | 这些变化，会变成回报。 | Those changes turn into return. |
| ROI → Demo | 做决定之前，先看看它实际怎么工作。 | Want to see it before you decide? |
| Demo → 案例 | 放进真实的生意里，乱的会变整齐。 | Now, inside a real business. |
| 案例 → 业务诊断 | 那第一步从哪里开始？先看清你的生意。 | So where do you start? With a review of your business. |
| 业务诊断 → 开始 | 准备好了，就告诉我们哪里最卡。 | When you are ready, tell us what is slowing you down. |

画面不画示意图：形状负责情绪和美感，意思交给文字。画面里的字是发光的文字，直接浮在形状旁边（不加框），跟着形状一起动。

## 粒子的质感

- **会流动**：粒子在显卡上实时模拟。每一颗都被一根"弹簧"拉向它在故事里该在的位置，同时在缓慢旋转的气流（curl noise）里漂；停住时弹簧紧、气流弱，形状清楚又微微在动；飞行时弹簧松、气流强，形状被拉成一股股光流
- **像镜头拍出来的**：对焦的地方粒子很细很清楚；离焦的粒子变成边缘清楚、略带亮边的圆形光斑；跑得快的粒子拉成一道短光痕；少数粒子会偶尔闪一下光
- **空气和调色**：背景有缓慢飘动的薄雾，颜色跟着每一章变，镜头移动时近处的雾比远处的移动得多；最后加一层电影调色：亮部柔和压缩、画面边缘一点点色散、暗部偏冷亮部偏暖、暗角和胶片颗粒
- 鼠标划过时，附近的粒子会被轻轻拨开

## 怎么浏览

- 就是普通的网页滚动：滚轮、触控板、手指（手机上有惯性）、键盘都可以。每段文字大约 1.25 屏，章与章之间多一点
- 画面会稍微滞后一点跟上滚动，所以鼠标滚轮一格一格的滚动也会变成连续的滑行
- 右边一排小竖线是十三章，点哪个就滑到哪一章
- 浮在画面里的字是网页文字，不是画上去的，所以清楚、能被搜索引擎读到；靠近屏幕边缘时会自动往里挪，不会被切掉

## 顶部栏和提问框

顶部只有语言切换、一个提问框和"预约业务诊断"按钮（手机上提问框缩成"问问题"）。

点提问框会打开一个提问面板，可以自己打字，也可以点建议的问题。回答都来自网站自己的文字，不需要服务器：按关键词找到最合适的一条，答案下面有"去看看"（首页直接滑到对应的那一章）和"打开页面 →"（打开详细的子页面）。

## 手机

手机上形状改成竖着排，放在屏幕上半部分；文字放在屏幕下方，背后有一层渐暗，保证读得清；案例的三栏变成上下排。粒子数量减少到约 6.5 万个，离焦光斑也小一些。

## 不支持 3D 的时候

以下情况不显示 3D，而是显示一个普通的、可以上下滚动的文字页面，内容、列表和链接都一样，最后也是联系表单：

- 浏览器或设备不支持 WebGL
- 系统开了"减少动态效果"
- 网址后面加 `?static`
- 禁用了 JavaScript

如果设备太慢（一半以上的帧超过 45 毫秒），页面会自己先降低清晰度，还不够再减少粒子数量。影片放完、联系表单盖住画面以后，3D 就不再画了。

## 文件结构

```
index.html          构建好的英文页面（直接用这个）
zh.html             构建好的中文页面
src/index.html      英文页面：每一段文字、浮在画面里的字、旁白、联系表单、提问框的问答
src/zh.html         中文页面（结构和英文一样）
src/world.js        三维世界：粒子、十三章的形状、镜头停靠点、滚动
src/ask.js          提问框
src/world.css       样式
assets/brand/mark.jpg   粒子取样用的 Logo 图案
assets/brand/       分享预览图（og-en.jpg、og-zh.jpg）、苹果主屏幕图标、512 图标、32 像素网站图标
assets/logo-icon.txt    顶部栏和页脚的小 Logo
favicon.ico         网站根目录的图标
tools/build.js      把以上文件打包成 index.html 和 zh.html
```

`index.html` 和 `zh.html` 各自是一个完整的文件（three.js、样式、Logo 都已经打包进去），双击就能用浏览器打开。在 Claude App 或 GitHub 里点开只会显示源代码，要先下载。原来的子页面（`zh-about.html`、`ai-agents.html` 等）没有改动，首页里的链接还是通向它们。

## 怎么改

改完 `src/` 下的文件后运行（第一次要先 `npm install`）：

```
npm run build
```

- **每一段文字**：`src/zh.html` / `src/index.html` 里 `<main class="story">` 下的 `<section class="st" data-ch="章">`，一个 section 就是镜头的一个停靠点，按顺序播放。`data-ch` 是它属于哪一章（`seed brand hero river storm bloom layer rise pillars gallery flow terrain final`）。加一段或删一段都可以，镜头会自动按顺序走
  - `st-k` 上面的小字编号，`<h2>` 标题（`<b>` 里的那一行、`<em>` 里的词是彩色的），`st-say` 一整句的大字，`st-lead` 大一点的正文，`st-k2` 小标题，`st-items` 列表（`<li><i>01</i><b>标题</b><span>说明</span></li>`），`st-big` 大数字，`st-note` 旁注，`st-case` 案例三栏（`<dt>`/`<dd>`），`st-links` 链接和按钮
  - `st-wide` 让较长的标题保持两行，`st-case-wrap` 是案例的宽版式，`st-only` 只在不支持 3D 的文字页面里显示
- **旁白**：`<div class="subs">` 里的 `<p class="sub" data-after="river">`，`data-after` 是它接在哪一章后面
- **浮在画面里的字**：`<div class="tags">` 里的 `data-tag`。`data-ch` 是它属于哪一章；`data-b="2"` 表示只在这一章的第 3 段（从 0 数）出现，不写就是整章都在；`data-hl="3"` 表示讲到这一章第 4 段时它亮起来。它们浮在哪里写在 `src/world.js` 的 `anchors` 里
- **镜头**：`src/world.js` 的 `stops()`，每一章一组停靠点（电脑和手机各一套），按段的顺序。大多数用 `orbit(中心, 绕的角度, 抬高的角度, 距离, 往右挪, 往上挪)` 写：从某个方向看着形状的中心，再把画面挪一下，让形状在文字的右边（手机上在文字上面）
- **节奏**：故事时间里每段占 1，章与章之间占 1.4；每段先停 `HOLD`（0.5），再飞向下一段。一个单位多少屏在 `SEG = VH * 1.25`
- **提问框的问答**：页面最后的 `<script type="application/json" id="ask-data">`。每一条 `{"k": [关键词…], "a": 回答, "go": 章, "href": 子页面, "label": 链接文字}`
- **粒子形状、颜色**：`src/world.js` 里的 `posAt()`、`colAt()` 和它们前面的函数

## 录屏

网址后面加 `?capture` 时页面不跟着滚动走，也不会自己动，可以在控制台用 `__w.scrollTo(12.3)` 设定故事时间（每一段从 `__w.T[段]` 开始），`__w.step(1/30)` 往前走一帧，用来一帧一帧地录视频。

## 分享预览图和网站图标

把网址发到微信、LinkedIn、WhatsApp、X 等地方时，会显示一张预览图（英文 `assets/brand/og-en.jpg`，中文 `assets/brand/og-zh.jpg`，1200×630）。上传网站时，要把 `assets/brand/` 文件夹和 `favicon.ico` 一起放到网站根目录。

字体从 Google Fonts 加载（Instrument Sans、Instrument Serif、Noto Sans SC、Noto Serif SC），没网时用系统字体。

之前的"短片 + 自动导览"版本还在 git 历史里（提交 `2988b68`）。
