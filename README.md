# NaxaStudio 首页（3D 粒子版）

英文版 `index.html`，中文版 `zh.html`。两个版本用同一套代码，右上角的 EN / 中文 互相链接。

## 创意

一切从一个小光点开始：打开首页，屏幕中间只有一个发光的"想法"。往下滑，镜头跟着这个点往前走，同一群粒子（电脑上 15 万个，手机上 6.4 万个）依次变成九个画面，讲完纳想是做什么的。没有一张图片、一个图标，所有画面都是这群粒子在三维空间里排出来的（three.js）。

| # | 画面 | 粒子在做什么 | 文字 | 详细内容在 |
| --- | --- | --- | --- | --- |
| 0 | 想法 | 一个发光的小点，轻轻呼吸 | "想法" | |
| 1 | 纳想 | 小点散开，拼成纳想的 Logo（颜色取自 Logo 原图），镜头慢慢绕着它转 | 把想法变成行动。没有你想象的那么难。 | |
| 2 | 为什么存在 | Logo 流成一条往远处去的河，河上三个光点：想法、行动、结果 | 帮助人从想法走向行动，从行动走向真实的结果。 | 关于 |
| 3 | 真正的卡点 | 河缠成四团乱线（琥珀色），每团是一个卡点：客户来了怎么回、线索怎么跟、资料怎么整理、内容怎么持续做 | 这些问题比技术本身更重要。 | |
| 4 | AI 解决方案 | 乱线理开，变成五个形状，对应五个 AI 助手（接待、销售跟进、营销、研究、流程）；名字可以点 | 围绕时间、成本和销售设计的实用方案。 | AI 方案 |
| 5 | 起步 AI 方案 | 一根光柱穿过四个光环，从下往上一层层搭起来：收集客户信息、生成摘要和下一步、准备回复草稿、建立流程清单 | 在雇完整团队之前，先让 AI 帮你处理最重复的客户和行政工作。 | 起步 AI 方案 |
| 6 | 案例 | 四个案例各一行：左边一团乱粒子，穿过箭头，右边变成整齐的光线 | 好的 AI 方案，应该先帮你少漏客户、少浪费时间、多抓住销售机会。 | 案例、Demo |
| 7 | AI 业务诊断 | 一张网格地图，六个机会点（客户咨询、销售跟进、营销任务、资料整理、行政流程、优先顺序），一条金色的路线把第一步连起来，一圈光在地图上扫 | 你有好的创业想法，但不知道从哪里开始？ | AI 业务诊断 |
| 8 | 开始 | 粒子收回成 Logo | 准备好了，就告诉我们哪里最卡。＋"预约业务诊断"按钮、页脚 | 联系 |

首页只放每一部分的要点；完整的文字都在原来的子页面上（`zh-about.html`、`ai-agents.html` 等，这些页面没有改动），每个画面的文字下面都有链接过去。

镜头在两个画面之间会稍微升起、拉远，粒子不是一起移动，而是一颗颗错开、打着旋飞到新位置，所以换画面像是同一群东西在变形。远处的粒子会虚化（景深），近处的清楚。

## 怎么浏览

- 滚轮、触控板、手指上下滑动；键盘 ↓ / 空格 / PageDown 下一个画面，↑ / PageUp 上一个，Home / End 回到开头 / 跳到最后
- 停手后会自动停在最近的一个画面上，不会停在两个画面中间
- 右边一排小竖线是九个画面，点哪个就去哪个
- 鼠标移动时，镜头会跟着轻轻偏一点
- 跟着地方走的小标签（"想法""行动""客户来了怎么回"……）是网页文字，不是画上去的，所以清楚、能被搜索引擎读到；靠近屏幕左右边缘时会自动往里挪，不会被切掉

## 顶部栏和提问框

顶部只有语言切换、一个提问框和"预约业务诊断"按钮（手机上提问框缩成"问问题"）。

点提问框会打开一个提问面板，可以自己打字，也可以点建议的问题。回答都来自网站自己的文字，不需要服务器：按关键词找到最合适的一条，答案下面有"去看看"（首页直接滑到对应的画面）和"打开页面 →"（打开详细的子页面）。找不到的问题会请对方直接联系。按 Esc 或 × 关闭。

## 手机

手机上画面改成竖着排（五个助手排成两列错开、案例标题放在每一行正上方、地图收窄），文字放在屏幕下方，背后有一层渐暗，保证读得清。粒子数量减少到 6.4 万个。

## 不支持 3D 的时候

以下情况不显示 3D，而是显示一个普通的、可以上下滚动的文字页面，内容和链接都一样（每一段还会把画面里的标签写成文字，比如五个助手的名字）：

- 浏览器或设备不支持 WebGL
- 系统开了"减少动态效果"
- 网址后面加 `?static`
- 禁用了 JavaScript

如果设备太慢（一半以上的帧超过 45 毫秒），页面会自己先降低清晰度，还不够再减少粒子数量。

## 文件结构

```
index.html          构建好的英文页面（直接用这个）
zh.html             构建好的中文页面
src/index.html      英文页面：每个画面的文字、跟着走的标签、提问框的问答
src/zh.html         中文页面（结构和英文一样）
src/world.js        三维世界：粒子、九个画面的形状、镜头、滚动
src/ask.js          提问框
src/world.css       样式
assets/brand/mark.jpg   粒子取样用的 Logo 图案
assets/brand/       分享预览图（og-en.jpg、og-zh.jpg）、苹果主屏幕图标、512 图标、32 像素网站图标
assets/logo-icon.txt    顶部栏的小 Logo
favicon.ico         网站根目录的图标
tools/build.js      把以上文件打包成 index.html 和 zh.html
```

`index.html` 和 `zh.html` 各自是一个完整的文件（three.js、样式、Logo 都已经打包进去），双击就能用浏览器打开。在 Claude App 或 GitHub 里点开只会显示源代码，要先下载。

## 怎么改

改完 `src/` 下的文件后运行（第一次要先 `npm install`）：

```
npm run build
```

- **每个画面的文字**：`src/zh.html` / `src/index.html` 里的 `<section class="st" data-stage="1">` … `data-stage="8"`。`st-k` 是上面的小字编号，`<h2>` 是标题（`<b>` 里的那一行是彩色的），`st-links` 是下面的链接。标题较长的画面加了 `st-wide`，让它保持两行。`class="st-only"` 的段落只在不支持 3D 的文字页面里显示
- **跟着地方走的小标签**：`<div class="tags">` 里的 `data-tag`。`idea` 想法、`brand` Logo 下的名字、`n0`–`n2` 河上的三个点、`p0`–`p3` 四个卡点、`a0`–`a4` 五个助手、`l0`–`l3` 四层、`c0`–`c3` 四个案例、`m0`–`m5` 地图上的六个点
- **提问框的问答**：页面最后的 `<script type="application/json" id="ask-data">`。每一条 `{"k": [关键词…], "a": 回答, "go": 画面编号, "href": 子页面, "label": 链接文字}`；`fallback` 是找不到时的回答
- **粒子形状、颜色、镜头位置**：`src/world.js`。九个画面的镜头在 `keys()` 里（电脑和手机各一套），形状在 `posAt()` 和它前面的几个函数里

## 录屏

网址后面加 `?capture` 时页面不会自己动，可以在控制台用 `__w.scrollTo(3)` 去第 3 个画面，`__w.step(1/30)` 往前走一帧，用来一帧一帧地录视频。

## 分享预览图和网站图标

把网址发到微信、LinkedIn、WhatsApp、X 等地方时，会显示一张预览图（英文 `assets/brand/og-en.jpg`，中文 `assets/brand/og-zh.jpg`，都是首页第一个画面的截图，1200×630）。上传网站时，要把 `assets/brand/` 文件夹和 `favicon.ico` 一起放到网站根目录。

字体从 Google Fonts 加载（Instrument Sans、Noto Sans SC），没网时用系统字体。

之前的"短片 + 自动导览"版本还在 git 历史里（提交 `2988b68`）。
