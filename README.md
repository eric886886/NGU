# NaxaStudio 动态首页（Motion 版）

英文版 `index.html`，中文版 `zh.html`。两个版本共用同一套样式和播放引擎，右上角的 EN / 中文 互相链接。

把 naxastudio.com 首页的全部内容重新设计成一部自动播放的"短片"：打开网页就从头开始播放，依次展示每一部分内容，约 2 分 53 秒。

短片放完后，页面自己顺滑地往下滚，接着展示其他页面的内容：AI 方案 → 起步 AI 方案 → Demo → 案例 → 关于 → AI 业务诊断 → 联系，最后是页脚。整页从头到尾不用点任何东西，英文版约 7 分 20 秒，中文版约 6 分 50 秒。随时可以自己上下滑动浏览。

## 创意

官网 Logo 本身就讲了一个故事：一串散开的小点（想法）汇成波浪，组成 N，最后变成向上的箭头（行动），对应口号 "Turn ideas into action"。

整部短片由一群粒子贯穿始终。所有粒子都从 Logo 图片里采样，每个粒子都保留了 Logo 上对应位置的颜色。每一章，它们变成一种不同的形态：

| 章节 | 版式 | 粒子形态 |
| --- | --- | --- |
| Intro | 品牌名、纳想 | 一个"想法"光点炸开，拼成 Logo |
| 01 首屏 | 粗黑体标题，配一行衬线斜体 "It’s not as hard as you think."；三句短语依次弹出；介绍段落逐词点亮 | Logo 移到右侧，一道光从左到右扫过 |
| 02 执行流程 | 一个超大单词以"解码"效果在 Capture → Organize → Build → Execute → Improve 之间切换，下方是五个节点和 Idea → Action 进度线 | 粒子流穿过五个节点：散乱 → 收拢 → 分成三条 → 拼成块 → 汇成一束 |
| 03 痛点 | 六条痛点大小不一、角度各异地散落成拼贴，风暴越乱，它们抖得越厉害 | 粒子风暴，夹杂琥珀色的"警报"粒子 |
| 04 AI 方案 | 轨道图：核心在上方，六个方案像行星一样排在轨道的下半弧 | 风暴平静成圆环，再从核心向每个方案射出数据流 |
| 05 业务成果 | 增长曲线图：六项成果是曲线上的六个标注点 | 一条光线逐点爬升，末端变成箭头 |
| 06 ROI | 发布会式大数字：2x-5x、5x-10x、3 levers 依次在屏幕中央计数，再飞回各自的位置 | 数字落位后，背后升起光柱 |
| 07 给创业者 | 旅程地图：三个里程碑沿上升的路径分布，终点是 "Plan My First AI System" 按钮 | "想法"光点沿路径逐个点亮里程碑，最后落到按钮上 |
| 08 从小处起步 | 技术图纸式的引线标注：三个入门项目从立方体引出 | 粒子搭成一个旋转的立方体（"一个系统"） |
| 结尾 | 标题、按钮、页脚 | 粒子重新拼回 Logo |

**排版**：粗黑体（Instrument Sans）配衬线斜体（Instrument Serif）。每章标题里的关键短语用衬线斜体，形成对比；章节编号、序号和标签用等宽字体。正文段落一出现是暗的，再按阅读速度逐词点亮，像卡拉 OK 字幕一样引导阅读。

原首页的文字全部保留，一字未改。只多了三处衔接文字：开场光点旁的 "Idea"、开场的 "AI execution systems"（取自原页头），以及在痛点和方案两章之间重复了一次原标题里的 "It’s not as hard as you think."。

## 短片之后：其他页面

每一节先是一张整屏的"片头卡"：章节号做成巨大的描边数字在标题后面慢慢漂移，标题逐词翻转入场，右边（手机上是上方）是这一节的粒子主视觉，全亮、一直在动。往下读正文时，主视觉缩小、变暗，退到屏幕边上。

| 顺序 | 内容来自 | 粒子主视觉 | 正文版式 |
| --- | --- | --- | --- |
| 10 | AI 方案（`ai-agents.html`） | 五个 AI 助手像卫星一样绕着一个核心转，各在一条倾斜的轨道上，数据从核心流向每一个 | 规格表，五个助手逐行扫入 |
| 11 | 起步 AI 方案（`base-ai-agent.html`） | 四层网格一层层落下叠起来，一道光从下往上扫过 | 四层"第一层工作"像台阶一样错开叠起 |
| 12 | Demo（`demo-center.html`） | 一把锁：先锁着发出琥珀色的光，然后打开，变成一个带播放键的窗口 | 六个小窗口，点 Demo 弹出原来的解锁表单 |
| 13 | 案例（`cases.html`） | 一团乱糟糟的"问题"（夹着琥珀色）挤过一道门（AI），出来变成一条向上的线和箭头 | 每个案例一条"问题 → AI 方案 → 结果"的时间线 |
| 14 | 关于（`about.html`） | Logo 本身，想法的小点不断流进 N | 宣言式的大段衬线字 |
| 15 | AI 业务诊断（`business-review.html`） | 一个倾斜的雷达，扫描光束转过时，六个"机会点"依次亮起 | 三步计划、六个诊断方向、三张输出卡片 |
| 16 | 联系（`contact.html`） | 一架纸飞机在空中绕圈飞，身后拖着长长的光尾 | 左边"适合咨询的问题"，右边原来的联系表单 |

各页面的文字（包括 Demo 解锁表单和联系表单）都是从原页面照搬的，一字未改；中文版用的是 `zh-` 开头那几页自己的内容。现有的子页面没有改动。

- 自动滚动像提词器：屏幕上已经能看全的内容就原地读完，下一段不在屏幕里时才往下移；每一段停多久按字数算（英文每秒约 5.6 个词，中文每秒约 11 个字）
- 正在读的那一段是亮的，其他内容变暗；左边一条光条跟着移到这一段旁边，光点从上往下走，走完就翻到下一段
- 标题的每个词从下面翻上来，落位时闪一下光；强调的那句话上有一道光泽来回扫过；正文按阅读速度逐词点亮，点亮的那个词带着光晕，像光标一样往前走
- 页面一动，背景就有动感：星星分几层远近，跟着页面以不同速度移动，滚得快时拉成光线；粒子会被页面带着稍微拖一下再弹回来，移动时拖出更长的尾巴
- 自己滚动（滚轮、触摸板、手指）时自动播放立刻停下，进度条跟着你的位置走；停下不动 7 秒后，播放键外圈走满一圈，从你看到的地方继续往下播。如果是按了暂停键，就一直停着
- 菜单和按钮里指向这些页面的链接（如 `ai-agents.html`、`contact.html`、`ai-agents.html#ai-sales`）会直接滚到本页对应的位置，不再跳走；隐私条款、另一种语言的页面照常打开
- Demo 解锁沿用官网的 `demo-center.js`（原样打包进来）：同样的密码、同样的表单检查，解锁状态和官网的 Demo 页面共用
- 填写联系表单或打开 Demo 表单时，自动播放会停下

## 中文版

`zh.html` 对应 naxastudio.com/zh：内容一字未改，链接都指向中文页面（`zh-business-review.html` 等），右上角 "EN" 回到英文版。针对中文的处理：

- 标题按字逐个出现，正文按阅读速度逐字点亮；借助浏览器自带的中文分词（`Intl.Segmenter`），只在词与词之间换行，不会把"销售""行政"拆到两行
- 强调短语用思源宋体（Noto Serif SC），中文不做斜体
- "实时执行流程"的大字用汉字乱码来解码
- 播放条、按钮、章节名都是中文
- 苹果设备使用本机的苹方字体，其他系统使用思源黑体（Noto Sans SC）

和英文版一样，只多了三处衔接文字：开场光点旁的"想法"（取自原页的"想法 → 行动"）、开场的"AI 执行力系统"（取自原页头），以及在痛点和方案两章之间重复了一次原标题"没有你想象的那么难。"。

## 怎么看

直接用浏览器打开 `index.html` 即可（在 Claude App 或 GitHub 里点开只会显示源代码，要先下载，再用 Safari / Chrome 打开）。所有代码、样式和 Logo 数据都已经打包在这一个文件里。

## 播放控制

- 底部播放条：播放 / 暂停、上一章 / 下一章；点击或拖动进度条可以跳到任意位置，鼠标悬停会显示章节名
- 点击画面空白处：暂停 / 继续
- 键盘：空格暂停，← → 切换章节，Home / End 跳到开头 / 结尾
- 滚轮（电脑）或上下滑动（手机）：像普通网页一样滚动，自动播放暂停，停下 7 秒后自动继续
- 倍速：1× / 1.5× / 2×
- "Read as page"（按页面阅读）：切换成普通的滚动网页，所有内容一次全部显示。系统开了"减少动态效果"的访客会直接看到这个模式；禁用 JavaScript 时也显示这个版本。
- 网址后面加 `?t=60` 可以从第 60 秒开始播放（`?t=200` 就是在后面的页面部分），加 `?read` 直接进入阅读模式
- 字体从 Google Fonts 加载（Instrument Sans、Instrument Serif），没网时会换成系统字体

## 文件结构

```
index.html             构建好的英文单文件页面（直接用这个）
zh.html                构建好的中文单文件页面
src/index.html         英文页面内容和每个元素的出场时间
src/zh.html            中文页面内容和每个元素的出场时间
src/motion.css         样式
src/motion.js          播放引擎、自动滚动和粒子
src/demo-center.js     官网的 Demo 解锁脚本（原样复制）
assets/                官网 Logo 原图，以及从中采样的粒子坐标、页头小图标
tools/build.js         把 src/ 和 assets/ 打包成 index.html 和 zh.html
tools/sample-logo.js   从 Logo 图片采样粒子坐标（需要 Playwright）
```

## 怎么改

改完 `src/` 下的文件后，运行：

```
node tools/build.js
```

时间都写在 `src/index.html` 和 `src/zh.html` 里：

- 每一章 `<section>` 上的 `data-dur` 是这一章的时长（秒）
- 元素上的 `data-at` 是它在本章第几秒出现，`data-dur` 是出现动画的时长
- `data-out` 是它在第几秒淡出；`data-outm` 也是淡出时间，但只在手机上生效（手机屏幕放不下时，先淡出段落，再让卡片接替它的位置）
- `data-read` 是段落开始逐词点亮的时间，`data-rate` 是每个词的间隔（默认 0.12 秒）
- ROI 数字上的 `data-land` 是它从屏幕中央飞回原位的时间；`data-count` 和 `data-cat` 分别是计数的目标值和开始时间
- `data-forms="storm@0"` 指定粒子在本章第几秒变成哪种形态

短片之后的页面部分（`<div class="tour">` 里）不按秒排，而是按滚动：

- `data-stop` 标记自动滚动的停靠点，停留时间按字数自动算；`data-dwell="12"` 可以手动指定停几秒
- `data-r` 是元素滚进屏幕后延迟多少秒出场；`data-rs` 让标题逐字出现，`data-rr` 让段落逐词点亮
- 每个 `<section data-tour>` 上的 `data-label` 是进度条上的章节名，`data-form` 是这一节的粒子形态

例如想让某一章多停留几秒，把这一章的 `data-dur` 调大就行。
