# NaxaStudio 首页（3D 粒子版）

英文版 `index.html`，中文版 `zh.html`。两个版本用同一套代码，右上角的 EN / 中文 互相链接。

## 创意

一切从一个小光点开始：打开首页，屏幕中间只有一个发光的"想法"。往下滑，镜头跟着这个点往前走，同一群粒子（电脑上约 15 万个，手机上约 6.5 万个）依次变成九个画面，讲完纳想是做什么的。没有一张图片、一个图标，所有画面都是这群粒子在三维空间里排出来的（three.js）。

整页是一部连续的短片，滚动条就是进度条：滑多少，故事就走多少；往回滑就倒着放。中间不分页、不跳转，停在哪里，画面就停在哪里（哪怕正变到一半）。每一段是这样走的：

1. 画面成形，这一段的标题跟着一个字一个字（英文是一个词一个词）浮上来，然后是小标题和链接
2. 继续往下滑，标题往上飘走、变模糊
3. 整个形状汇成一条旋转的光流，沿着镜头的路线流向下一个地方；这时屏幕中下方出现一句旁白，像电影字幕，把这一段和下一段接起来
4. 光流在下一个地方散开，拼成新的形状，新的标题浮上来

画面不画示意图，也不在画面上贴标签：形状只负责情绪和美感，意思交给文字。首页只放每一部分的要点；完整的文字都在原来的子页面上（`zh-about.html`、`ai-agents.html` 等，这些页面没有改动），每个画面的文字下面都有链接过去。

镜头在两个画面之间会稍微升起；停在一个画面时会慢慢往前推近一点。粒子不是一起出发，而是一颗颗错开，所以光流是连续的：一头还在旧形状里，一头已经在拼新形状。画面里的小标签也跟着画面一个接一个出现。

## 粒子的质感

- **会流动**：粒子在显卡上实时模拟。每一颗都被一根"弹簧"拉向它在故事里该在的位置，同时在缓慢旋转的气流（curl noise）里漂；停住时弹簧紧、气流弱，形状清楚又微微在动；飞行时弹簧松、气流强，形状被拉成一股股光流
- **像镜头拍出来的**：对焦的地方粒子很细很清楚；离焦的粒子变成边缘清楚、略带亮边的圆形光斑（同样的光摊到更大的圆上，所以更淡）；跑得快的粒子拉成一道短光痕；少数粒子会偶尔闪一下光
- **细节**：卡点的能量体从左上方受光，裂开的边缘发亮、里面暗；花瓣从根部的深色渐变到尖上的浅色，叶脉更亮；Logo 上有一道光慢慢扫过；星点分布在路线周围，远的慢慢隐入黑暗
- **空气和调色**：背景有缓慢飘动的薄雾，颜色跟着每一段变（卡点偏琥珀色，起步方案偏青色……），镜头移动时近处的雾比远处的移动得多；最后加一层电影调色：亮部柔和压缩、画面边缘一点点色散、暗部偏冷亮部偏暖、暗角和胶片颗粒
- 鼠标划过时，附近的粒子会被轻轻拨开

## 怎么浏览

- 就是普通的网页滚动：滚轮、触控板、手指（手机上有惯性）、键盘（↓ ↑ 空格 PageDown PageUp Home End）都可以；大约每 1.5 屏是一个画面，整页约 13 屏
- 画面会稍微滞后一点跟上滚动，所以鼠标滚轮一格一格的滚动也会变成连续的滑行
- 右边一排小竖线是九个画面，点哪个就滑到哪个
- 鼠标移动时，镜头会跟着轻轻偏一点
- 画面上只有前三段有小标签（"想法"、Logo 下的名字、河上的"想法 / 行动 / 结果"），它们是网页文字，不是画上去的，所以清楚、能被搜索引擎读到；靠近屏幕左右边缘时会自动往里挪，不会被切掉

## 顶部栏和提问框

顶部只有语言切换、一个提问框和"预约业务诊断"按钮（手机上提问框缩成"问问题"）。

点提问框会打开一个提问面板，可以自己打字，也可以点建议的问题。回答都来自网站自己的文字，不需要服务器：按关键词找到最合适的一条，答案下面有"去看看"（首页直接滑到对应的画面）和"打开页面 →"（打开详细的子页面）。找不到的问题会请对方直接联系。按 Esc 或 × 关闭。

## 手机

手机上画面改成竖着排（五个助手排成两列错开、案例标题放在每一行正上方、地图收窄），文字放在屏幕下方，背后有一层渐暗，保证读得清。粒子数量减少到约 6.5 万个，离焦光斑也小一些。

## 不支持 3D 的时候

以下情况不显示 3D，而是显示一个普通的、可以上下滚动的文字页面，内容和链接都一样（每一段还会把画面里的标签写成文字，比如五个助手的名字）：

- 浏览器或设备不支持 WebGL
- 系统开了"减少动态效果"
- 网址后面加 `?static`
- 禁用了 JavaScript

文字页面里没有旁白，只有每一段的标题和内容。

如果设备太慢（一半以上的帧超过 45 毫秒），页面会自己先降低清晰度，还不够再减少粒子数量。

## 文件结构

```
index.html          构建好的英文页面（直接用这个）
zh.html             构建好的中文页面
src/index.html      英文页面：每个画面的文字、跟着走的标签、提问框的问答
src/zh.html         中文页面（结构和英文一样）
src/world.js        三维世界：粒子、九个画面的形状、镜头、滚动
src/ask.js          提问框
src/world.css       样式
assets/brand/mark.jpg   粒子取样用的 Logo 图案
assets/brand/       分享预览图（og-en.jpg、og-zh.jpg）、苹果主屏幕图标、512 图标、32 像素网站图标
assets/logo-icon.txt    顶部栏的小 Logo
favicon.ico         网站根目录的图标
tools/build.js      把以上文件打包成 index.html 和 zh.html
```

`index.html` 和 `zh.html` 各自是一个完整的文件（three.js、样式、Logo 都已经打包进去），双击就能用浏览器打开。在 Claude App 或 GitHub 里点开只会显示源代码，要先下载。

## 怎么改

改完 `src/` 下的文件后运行（第一次要先 `npm install`）：

```
npm run build
```

- **故事的时间**：滚动换算成"故事时间"，第 k 个画面从 k 开始：k 到 k+0.4 画面停住（标题在 k−0.2 到 k+0.04 之间浮上来，k+0.3 到 k+0.42 之间飘走），k+0.4 到 k+1 飞向下一个画面。每个画面占多少屏在 `src/world.js` 的 `SEG = VH * 1.5`，停住的比例是 `HOLD`
- **旁白**：`<div class="subs">` 里的 `<p class="sub" data-t="1.46,1.78">`，`data-t` 是它出现和消失的故事时间（第一句写 `-1`，表示打开页面就出现）
- **每个画面的文字**：`src/zh.html` / `src/index.html` 里的 `<section class="st" data-stage="1">` … `data-stage="8"`。`st-k` 是上面的小字编号，`<h2>` 是标题（`<b>` 里的那一行是彩色的），`st-links` 是下面的链接。标题较长的画面加了 `st-wide`，让它保持两行。`class="st-only"` 的段落只在不支持 3D 的文字页面里显示
- **跟着地方走的小标签**：`<div class="tags">` 里的 `data-tag`。`idea` 想法、`brand` Logo 下的名字、`n0`–`n2` 河上的三个点。第 3 到 5 段标题下面那行小字是 `<p class="st-list">`
- **提问框的问答**：页面最后的 `<script type="application/json" id="ask-data">`。每一条 `{"k": [关键词…], "a": 回答, "go": 画面编号, "href": 子页面, "label": 链接文字}`；`fallback` 是找不到时的回答
- **粒子形状、颜色、镜头位置**：`src/world.js`。九个画面的镜头在 `keys()` 里（电脑和手机各一套），形状在 `posAt()` 和它前面的几个函数里

## 录屏

网址后面加 `?capture` 时页面不跟着滚动走，也不会自己动，可以在控制台用 `__w.scrollTo(3.2)` 设定故事时间，`__w.step(1/30)` 往前走一帧，用来一帧一帧地录视频。

## 分享预览图和网站图标

把网址发到微信、LinkedIn、WhatsApp、X 等地方时，会显示一张预览图（英文 `assets/brand/og-en.jpg`，中文 `assets/brand/og-zh.jpg`，都是首页第一个画面的截图，1200×630）。上传网站时，要把 `assets/brand/` 文件夹和 `favicon.ico` 一起放到网站根目录。

字体从 Google Fonts 加载（Instrument Sans、Noto Sans SC），没网时用系统字体。

之前的"短片 + 自动导览"版本还在 git 历史里（提交 `2988b68`）。
